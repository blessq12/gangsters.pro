# Company — события

## Текущее состояние

В runtime BC **нет** доменных или интеграционных событий:

- нет `Event` / `Listener` при сохранении из Filament;
- use case'ы — синхронный read без побочных эффектов.

Изменения видны при следующем `GET /api/company/*` (общая БД).

## Сейчас

Для агента: **не искать** `Company*Event` — их нет.
