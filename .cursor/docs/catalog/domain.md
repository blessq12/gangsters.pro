# Catalog — слой домена

Ядро BC: сущности, значения, перечисления и контракты доступа к данным. Без Laravel, без HTTP, без Filament.

## Сущности и контракты

| Элемент | Смысл |
|---------|--------|
| `Category` | Категория меню (имя, slug, порядок, активность) |
| `Product` | Товар как позиция витрины |
| `ProductSet` | Набор с линиями состава |
| `Tag` | Справочник меток |
| `CategoryItem` | Ссылка «категория → позиция каталога» с видом (`product` / `set`) |
| `CatalogItem` | Общий контракт товара и набора на витрине |

## Value objects

| VO | Смысл |
|----|--------|
| `Nutrition` | КБЖУ и база расчёта (`per_100g`) |
| `ProductSetLine` | Товар в составе набора + количество |

## Перечисления

| Enum | Значения |
|------|----------|
| `CatalogItemKind` | `product`, `set` |
| `ProductStatus` | `active`, `archived` |

## Репозитории (порты)

| Порт | Ответственность |
|------|-----------------|
| `CategoryRepository` | Категории и состав категории |
| `CatalogItemRepository` | Товары и наборы по id, активные выборки |
| `TagRepository` | Активные теги |

Домен **не знает** про таблицы `PRD_*` и Eloquent — только интерфейсы и чистые типы.

## Инварианты (семантика)

- В категорию попадают только **активные** позиции, известные каталогу.
- Товар и набор — разные виды одной таблицы хранения, но в домене разделены сущностями/видом.
- Архивная позиция не должна отображаться на витрине.
