# Catalog — обзор BC

**Тип:** Core Domain  
**Роль:** справочник витрины — что видит клиент в меню и что настраивает оператор в админке.

## Семантика

| Термин | Смысл |
|--------|--------|
| **Категория** | Раздел меню с упорядоченным списком позиций |
| **Товар** | Продаваемая позиция с ценой, описанием, пищевой ценностью, составом, тегами, изображениями |
| **Набор** | Позиция каталога, собранная из нескольких товаров (состав набора и количества) |
| **Тег** | Справочная метка для витрины (новинка, хит и т.п.) |
| **Состав категории** | Связь категория ↔ товар/набор с порядком сортировки |
| **Позиция каталога** | Обобщение: товар и набор равноправны в категории (`CatalogItem`) |

## Границы

- **Внутри BC:** структура меню, карточки товаров/наборов, теги, медиа товара, порядок в категории.
- **Снаружи:** цены в корзине, правила заказа, оплата, доставка, клиенты — другие контексты.
- Публичный контракт — **только чтение** (`GET /api/catalog`).
- Запись — **только Filament** (`/admin/catalog`).

## Хранение

Единая группа таблиц `PRD_*` (категории, товары/наборы в одной таблице продуктов, теги, связи, изображения, строки набора).
