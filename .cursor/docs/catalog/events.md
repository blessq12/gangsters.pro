# Catalog — события

## Текущее состояние

В runtime BC **нет** доменных или интеграционных событий каталога:

- нет Laravel `Event` / `Listener` для категорий, товаров, наборов, тегов;
- нет outbox и публикации в другие контексты при сохранении из Filament;
- `GetCatalogUseCase` — синхронный read без побочных эффектов.

Изменения в админке сразу видны витрине при следующем `GET /api/catalog` (общая БД).

## Семантика (когда появятся)

Ожидаемые типы событий для BC (ориентир, не реализовано):

| Событие | Когда | Потенциальные потребители |
|---------|--------|---------------------------|
| Категория создана/изменена/деактивирована | Мутация категории | Кэш витрины, поиск, аналитика |
| Позиция каталога изменена/архивирована | Мутация товара/набора | Корзина, промо, внешние агрегаторы |
| Состав категории изменён | Reorder / add / remove | Витрина, SEO |
| Теги синхронизированы | Привязка к товару | Витрина, фильтры |
| Изображение товара добавлено/удалено | Relation manager | CDN, превью |

## Где публиковать (целевая точка)

Application-слой после Command-сценариев — единая точка публикации, не Filament и не Eloquent hooks.
