# Админка: доставка (Операции)

## Где править

**Операции → Доставка** (`/admin/operations?tab=delivery`)

Одна форма объединяет:

- **Тарифы и параметры:** часы доставки (текст), мин. заказ (коп.), плата за доставку (коп.), среднее время доставки (мин)
- **Зона на карте** и координаты кухни

## Связь с checkout

- `min_order_amount_kopecks` — порог: при сумме заказа **ниже** порога к доставке добавляется `delivery_fee_kopecks` (см. `CompanyDeliveryTermsPort` / корзина).
- Публичный API и SPA по-прежнему читают эти поля из `GetSystemCompanyUseCase` (таблица `companies`).

## Компания → Профиль

Режим работы (часы и расписание по дням) остаётся в **Компания → Профиль**. Тарифы доставки там **не редактируются**.
